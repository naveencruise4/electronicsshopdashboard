# 📊 Electronics Shop Dashboard

Upload your Excel files and instantly create beautiful, interactive dashboards!

## Features

✅ **Upload Excel/CSV Files** - Support for .xlsx, .xls, and .csv formats  
✅ **Instant Dashboards** - Automatic chart generation based on your data  
✅ **Interactive Charts** - Bar, Line, and Pie charts  
✅ **Data Filtering** - Search and filter your data easily  
✅ **Summary Statistics** - Get automatic summaries of numeric columns  
✅ **Data Tables** - Browse and sort your raw data  
✅ **100% Private** - All processing happens in your browser, no server uploads  
✅ **Mobile Responsive** - Works on desktop, tablet, and mobile  
✅ **Completely Free** - No registration, no payments, no limits
